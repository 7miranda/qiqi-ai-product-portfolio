# Crossbound · 2026-10-28 细节修订

## 视觉边界

以现有深黑园区为基准，保留地球、园区建筑、模型比例、内容顺序和主要留白。
采用钢灰表面、冷青细线和荧光绿主操作。绿边与勾选表示选中，外侧青色线表示键盘焦点；
普通操作、禁用、错误提示各有独立状态。短角标只用于弹层边缘，不增加常驻闪烁或装饰按钮。

全站使用四个视觉层：`styles.css` 负责共享状态，`home.css` 负责完整首页，
`workspaces.css` 负责所有原生业务页面，`operations.css` 负责七个新经营房间。
首页覆盖导航、地球周边信息、情报、开场故事、Agent、企业服务、新闻案例及生活场景；
业务层覆盖市场、商品、供货、生产、达人、广告、订单、经营账、成就、教程与服务结果。
原生30类视图均经过同一个 `campaign-panel` 文档层，补充页保留其原有结构。
保留商品图 contain、达人素材 3:4 cover 和上架预览 3:2；不对图片或画布做整体拉伸。
新业务房间采用相同冷色材质，替换卡通阶梯材质与粉紫照明，保留模型、相机、碰撞和业务动作。
中等桌面宽度的通知改用独立消息行，园区高度保持 520/560px，父容器随内容撑开，避免遮住楼宇入口。
移动端服务名称按语义分两行，勾选与名称分开，返回操作保持左侧。
390px 与 320px 首页标题按完整语义分两行，避免与正文和主操作碰撞。
商品库及供货预览通过容器尺寸触发原有相机等比取景，模型与说明避开固定操作条。
