# Crossbound 3D 世界方案 v2（2026-10-25 晚，取代 v1 等距沙盘版）

> **方向纠正（用户 2026-10-25 晚定版）**：v1 的"等距总部沙盘"作废——看得到、走不进，不是要的感觉。v2 要的是**真的走进去的世界**：赛博朋克 2077 式沉浸 + 宝可梦 Switch 式"大世界 + 进建筑"的结构。**侧边栏点击同步作废**：导航不再是点菜单，而是走路；操作不再是填表单，而是进空间里动手。

## 1. 两个参照，分别借什么（借结构，不借画质）

| 参照 | 借什么 | 不借什么 |
|---|---|---|
| **赛博朋克 2077** | 沉浸结构：可走动的世界、可进入的室内、世界里的屏幕（墙面大屏、终端机）、任务标记（头顶/地面指引）、NPC 对话推进、霓虹夜景的密度感 | 写实画质、枪战、开放世界规模——solo 团队做不到，也不做 |
| **宝可梦 Switch（朱紫 / 阿尔宙斯 / 剑盾）** | **核心结构模板**：第三人称跟随视角；大世界（城镇/原野）自由走动；走到建筑门口 → 进门 → 室内是一个完整空间；NPC 对话、任务目标指引；卡通渲染 | 回合制战斗、收集养成系统 |

**一句话定性**：宝可梦的结构 + 赛博朋克的皮 = "霓虹卡通"世界：走得进去、看得懂、做得起。

## 2. 视角定版：第三人称跟随（宝可梦式）

- **主视角：第三人称跟随**。角色始终可见——玩家看到的是"我的出海合伙人"在世界里走，代入感比第一人称更强；手机端可用虚拟摇杆 + 点触操作；不晕 3D（第一人称在手机上又晕又难操作）。
- **备选**：第一人称（赛博式）作为后期可切换视角，不阻塞 v2 落地。
- **相机**：跟随 + 室内自动拉近；进门时镜头推近过场，强化"进入一个世界"的感觉。

## 3. 世界结构：大世界 Hub + 七个室内世界

**大世界 Hub：总部街区**——一条霓虹街道 + 总部大楼，玩家出生点；可自由走动；小地图 + 任务标记（地面光柱 + 方向箭头，宝可梦式防迷路）；街上有路人 NPC、广告屏、世界地图终端（选市场在这里做：走到终端前按交互，不是点侧边栏）。

**七个环节 = 七个室内世界**。流程永远是：**走到门口 → 推门进入 → 在里面操作 → 完成 → 出口（或直接传送到下一个入口）**。每个世界都有自己的美术主题和交互物：

| 顺序 | 世界（建筑/房间） | 对应环节 | 在里面怎么操作（不是点面板） |
|---|---|---|---|
| 1 | 选品展厅 | 选商品、选供应商 | 走到货架前，拿起商品看属性；供应商 NPC 站在展位后，跟他对话谈价、看样品 |
| 2 | 定价财务室 | 定价、备货量 | 站在控制台前拨价格牌；货箱随备货量在房间里变多变少，堆满了就是"备多了" |
| 3 | 商品页工作室 | 上架、标题主图风格 | 一面大屏就是商品页，拼标题、换主图风格，分数实时跳在大屏上 |
| 4 | 直播间 / 推广室 | 选推广渠道 + 二级决策 | 内容号：主播小人开播；广告：投流大屏实时烧钱；达人：达人 NPC 走进来跟你谈合作 |
| 5 | 物流仓 | 选履约、头程 | 点货箱选线路；空运飞机、陆运货车、海运货轮在仓外动画里跑起来，慢和快看得见 |
| 6 | 财报结算厅 | 结算、看三大表 | 利润瀑布、现金流曲线投在会议室大屏上；现金流断了，整个房间灯变红（教学点可视化） |
| 7 | 荣誉墙展厅 | 成就、共建者徽章 | 徽章挂墙上；共建者 NPC/信箱收反馈（原右侧消息栏的"共建者专线"搬到这里当面交） |

**原侧边栏信息的去向（全部搬进世界）**：

| 原来在哪 | 现在在哪 |
|---|---|
| 右侧消息栏 / 总部来电 | 总部大楼的接待员 NPC：走到她面前，她当面跟你说；头顶气泡 + 对话框 |
| 步骤面板 / 任务清单 | 地面光柱 + 小地图标记 + HUD 顶部一句话任务目标（"去选品展厅挑 1 件商品"） |
| 战报 / 财报面板 | 结算厅大屏（世界内屏幕，diegetic UI） |
| 共建者专线入口 | 荣誉墙的共建者信箱 NPC |
| 设置 / 帮助 / 逻辑卡 | 总部大楼里的"帮助终端"（一台可交互的机器） |

**HUD 只留三件**：现金、任务目标一句话、小地图。其他一切进世界。

## 4. 视觉：霓虹卡通（画质边界先说清）

- **渲染**：卡通渲染（toon shader）+ 低多边形模型（宝可梦式），不是写实。
- **氛围**：赛博霓虹夜景——霓虹招牌、发光材质、雾效、雨夜反光（便宜做法：发光贴图 + 地面反射贴图，不做实时光追）。
- **边界**：不追 2077 的写实画质，追的是"走进去的感觉"——能走路、能进门、能跟 NPC 说话、屏幕长在世界里。这四条有了，沉浸感就立住了。

## 5. 技术路线 v2（引擎不动，只换"怎么玩"）

- **引擎层不动**：v11/v2 的 core 与 model 继续算账；3D 世界是新的表现层 `v3/world/`，只把算好的 state 喂给世界渲染。
- **控制器**：three.js 第三人称控制器（见 §6 模板），WASD + 鼠标视角（桌面）/ 虚拟摇杆 + 点触交互（移动端）。
- **场景加载**：按需加载——首屏只加载 Hub 街区，进门时再加载室内世界（带一个短推门过场，掩盖加载）；一次只驻留两个场景，控制内存。
- **交互**：靠近可互动物体 → 出现提示（按 E / 点一下）→ 对话框或控制台界面（界面本身做成世界里屏幕的样式，不是系统弹窗）。
- **性能红线**：单场景面数上限、低多边形资产、灯光烘焙不实时算、阴影只开关键光；低端机自动降画质（分辨率/阴影/粒子三档）。
- **兜底（定版）**：移动端默认仍进世界（虚拟摇杆）；仅为低端机/晕 3D 玩家保留一个"经典平面模式"开关——是无障碍兜底，不作主推，不恢复侧边栏为主界面。

### v1 参考的处理

- **作废**：等距沙盘路线（roomlab、3D-Isometric-Room-Game 的等距视角）——看得到走不进，不符合 v2 方向，不再采用。

## 7. 落地顺序 v2（先验证"走进去的感觉"，再扩世界）

- **P0（验证）**：Hub 街区 + 第三人称行走 + 进出选品展厅完整闭环（进门 → 挑 1 件商品 → 出门）。用户确认"走进去的感觉对了"才继续。
- **P1（全通）**：七个世界全部打通，环节顺序与现有 stage 一致；老存档直接进世界（不丢进度）。
- **P2（世界感）**：NPC 对话（接待员/供应商/达人）、世界内屏幕（大屏财报、控制台）、任务标记与过场动画、REQ-050 教学改成"接待员带路 + 地面光柱"。
- **P3（氛围）**：霓虹夜景、天气、音效、跨轮大楼成长（工位变多、招牌变亮）。

## 8. 交给 Codex 的清单 v2

1. 本文档 v2 + §6 的控制器模板（先读 three-player-controller）。
2. 约束：**引擎不动**；表现层新目录 `v3/world/`；**侧边栏与步骤面板删除**，信息全部按 §3 的表搬进世界；先交付 P0（Hub + 行走 + 选品展厅闭环），用户确认感觉后再扩。
3. 验收：桌面 WASD + 鼠标、移动虚拟摇杆 + 点触都能走完 P0；第 1 轮只开简化世界；第 2 轮新世界出现时配接待员带路；低端机自动降画质不卡死；老存档进度不丢。
