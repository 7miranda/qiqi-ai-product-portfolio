# Crossbound 3D 世界体验反馈与双模式需求（2026-10-25，用户实测反馈）

> 来源：用户实测 3D 版（选品展厅截图 + 商品信息板截图 + 旧平面版截图对照）后提出的 3 点意见，整理成 Claude 可直接执行的条目。
> 先说仓库现状（核对过，2026-10-25 晚）：仓库最新代码提交仍是 10-23 的平面版 demo（60b188c），**3D 版代码尚未推到仓库**——用户玩到的 3D 应是 Claude 本地或其他预览链接的版本。请 Claude 先把 3D 版代码同步到仓库，否则产品侧无法对照验收；本反馈按截图中的 3D 版为准。

## 1. 商品实物感丢了：从"展位卡片"回到"看得见的货"

**问题**：3D 展厅里商品只剩展位 + 信息卡，模型小到看不清是什么东西；旧版有产品实物呈现与打开动效，新版把这个优点丢了。展厅是第一印象，货看不清等于选品环节的"手感"没了。

- **F-001 每个商品一个可辨识的实物模型**：展位上放按品类做的低多边形实物——灯就是灯、风扇就是风扇、耳机就是耳机，5 米外能认出品类；单模型 ≤5,000 面（沿用 3D-073 上限）。做不到全品类建模时，退而求其次：展位立牌上贴产品实物图（2D 图片贴片），**不得只剩文字卡**。
- **F-002 拿起动画**：按 E 拿起 → 商品从展位飞到角色手上（0.4 秒缓动）+ 展位光圈变色；放回去反向动画；动画期间角色锁定（沿用 3D-016）。
- **F-003 打开 / 展开动效**：商品信息板打开时，模型做一个"打开"动作，每品类至少 1 个标志性动效：灯亮起来、风扇转起来、耳机盒盖打开、行李箱展开、升降桌升起来……信息板本身沿用现有版式（商品名、卖点句、参考价、进货成本、供货交期、"放回去 / 就它了"两按钮），只加动效、不改信息结构。
- **F-004 选中态**：选中的商品展位常亮绿灯 + 模型放大 20% + 漂浮小标签"已选"；其余展位不变暗（可反悔重选，未确认前随时换，沿用 3D-019）。
- **验收**：随机抽 6 个商品，5 米外能说出品类；拿起 / 放回 / 打开动效齐全；信息板数字与引擎一致。

## 2. 刷新后闪现初始平面（Bug，必须修）

**问题**：刷新页面后，进入游戏会有一瞬间闪现初始状态的平面（旧版首页 / 步骤面板），然后才切到 3D。

**根因推测（需 Claude 核对代码，不作定论）**：旧平面 DOM 默认先渲染，3D 初始化完成前没有加载门；或存档中的模式选择读得比首帧渲染晚，导致先按默认平面渲染了一帧再纠正。

- **B-001 加载门**：页面加载后先显示加载屏（总部大楼夜景底 + 进度条 + "正在布置世界"），在 3D 场景首帧渲染完成**且**存档恢复完成之前，禁止渲染任何游戏平面 UI（包括旧版首页、步骤面板、消息栏）。
- **B-002 模式先行**：存档中的模式选择（3D / 2D）必须在首帧前读出；无存档的新玩家先出模式选择屏（见 §3 M-001），选完再进对应界面；任何情况下不得先渲染默认平面再切换。
- **B-003 刷新恢复**：刷新后回到刷新前的位置与世界状态（沿用 3D-080 断点续玩），不得回到"初始状态"；已确认的选择（商品、供应商、价格、备货、渠道、履约）刷新后全部保留。
- **B-004 验收**：连续刷新 10 次，录屏逐帧检查：不得出现任何一帧旧平面；从点击进入到可操作 ≤5 秒（4G 网络，沿用 3D-077），超时显示进度、不得白屏。

## 3. 双模式：2D 与 3D 共存、可选、可切换（用户定版：不是二选一，是都要）

**背景**：有人晕 3D，觉得还是 2D 好。用户定版：首先就给别人选择，并且随时可以切换，2D 和 3D 都有。

- **M-001 首次进入选择屏**：新玩家第一次进游戏，先出一张选择屏，两张卡：①「3D 世界」（走进去玩，配一张选品展厅图；一句话：走路进房间动手操作）；②「2D 经典」（平面点选，配一张平面版图；一句话：点面板操作，数据规则完全一样）。选后记住选择，可改。
- **M-002 随时切换**：切换入口放两处：①设置终端（3D 世界内）/ 设置菜单（2D 内）；②顶栏常驻一个小切换按钮（图标：3D 立方体 ↔ 2D 平面）。切换 ≤1.5 秒（带过场），不重进游戏、不丢轮次。
- **M-003 进度互通**：同一存档；切换时状态映射沿用 3D-079（正向：stage → 世界状态；反向亦然：2D 做到第 3 步 → 切 3D 落在 W3 门前；3D 在 W4 里 → 切 2D 落在第 4 步面板）。切换后已确认项（商品、供应商、价格、备货、渠道、履约）全部保留。
- **M-004 规则一致**：两个模式共用同一套引擎与数值（价格、税率、退款、转化率、达标阶梯），不得出现"3D 一个数、2D 一个数"；战报、成就、共建专线、留资在两模式下都能完成。
- **M-005 2D 模式定义**：就是现有平面版（步骤条 01–06 + 面板 + 右侧消息栏 + 园区导览，见对照截图），继续维护，不删；不得以"已全面 3D 化"为由停更 2D。
- **M-006 晕 3D 舒适度（3D 内设置）**：视角灵敏度滑杆（默认 50%）、关闭镜头晃动（默认关晃动）、FOV 调节（55–75°）；晕的玩家切 2D 永远是选项（M-002）。
- **M-007 默认值**：新玩家首次选择屏不预选（必须手动点，防误进 3D 致晕）；老玩家沿用上次选择；低端机（首启帧率检测 <30）首选推荐 2D（只推荐，不强制）。
- **验收**：新号走选择屏，两路各通一轮；中途切换 3 次状态不错乱；刷新后模式不变；晕 3D 玩家全程 2D 可通关。
