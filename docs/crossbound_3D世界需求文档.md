# Crossbound 3D 世界需求文档（v1，2026-10-25）

> 依据：《3D 视觉与空间化方案 v2》（2026-10-25 晚，用户定版：可走入的 3D 世界，赛博朋克 2077 式沉浸 + 宝可梦 Switch 式"大世界 + 进建筑"结构，侧边栏作废）。
> 本文档是专项需求文档，编号 3D-001 起；与主 PRD（crossbound_v1.1_需求文档.md，50 REQ）并行，冲突时以主 PRD 的数值与规则为准、本文件只定"世界里的表现与交互"。定版后可折入主 PRD 作 REQ-051 起。
> 写作口径：所有数值、状态、条件全部定死，不留"待定"；每条带验收。

## §0 总则

- **3D-001 方向定版**：游戏主界面是一个可走动的 3D 世界，不是等距沙盘、不是面板 + 侧边栏。玩家操控一个角色，在世界里走路、进门、动手操作。
- **3D-002 视角定版**：第三人称跟随视角（宝可梦式）为唯一首发视角；第一人称切换为后期备选，不在本文件内实现。
- **3D-003 视觉定版**：霓虹卡通——卡通渲染（toon shader）+ 低多边形模型 + 赛博霓虹夜景（霓虹招牌、发光材质、雾效）。不做写实画质。
- **3D-004 侧边栏死刑**：删除现有右侧消息栏与步骤面板。所有信息按 §3 的表搬进世界或 HUD；不得以"先保留侧边栏过渡"为由并存两套导航。
- **3D-005 引擎不动**：v11/v2 的 core 与 model 只算账，不改规则、不改数值。3D 层是新表现层目录 `v3/world/`，只读取引擎 state 并把玩家在世界里的操作翻译回原有 stage 输入。世界完成条件 = 原环节完成条件，不新增任何胜负规则。
- **3D-006 术语**：世界 = 一个可走动的 3D 场景；Hub = 总部街区（大世界）；室内世界 = 每个环节对应的建筑内部；交互点 = 靠近后可操作的东西（货架、控制台、NPC、屏幕）；任务标记 = 地面光柱 + 小地图标记 + HUD 任务句；世界内屏幕 = 长在世界里的屏幕（墙面大屏、控制台屏、终端屏），区别于系统弹窗。
- **3D-007 存档兼容**：老存档（平面版进度）直接进世界：按原 stage 映射到世界状态（见 §11），不丢进度、不重置轮次。

## §1 世界总览

- **3D-008 Hub：总部街区**。玩家出生点；一条霓虹街道 + 总部大楼正门；地面可自由走动，无空气墙外的可达区域外全部用建筑/路障封边。
- **3D-009 Hub 建筑清单（全部可走近，不可进入的只做外观）**：
  1. 总部大楼（正门 = 回 Hub 的锚点，也是七个世界的入口集中处：一楼大厅有七扇门，每扇门上方挂世界名牌与状态灯）；
  2. 世界地图终端（选市场：走到终端前交互，见 3D-030）；
  3. 帮助终端（原 HELP 逻辑卡：走到机器前交互，见 3D-031）；
  4. 装饰建筑 3 栋（不可进入：便利店、广告屏大楼、停车场），只做外观与霓虹招牌。
- **3D-010 七扇门的状态灯**：未解锁 = 灰色 + 锁图标；当前世界 = 金色光柱 + 门敞开；已完成 = 绿灯常亮；门上方名牌文字 = 世界名（如"选品展厅"）。
- **3D-011 出生与重进**：新玩家出生在总部大楼门口，接待员 NPC 站在门口 3 米内；老玩家重进落在"当前世界对应的门前"，不落在随机位置。
- **3D-012 小地图**：右上角圆形小地图；显示：玩家位置与朝向、七扇门位置（颜色同状态灯）、当前任务标记（金色感叹号）；小地图不显示未解锁世界的内部结构，只显示门的位置。

## §2 角色与相机（第三人称）

- **3D-013 角色**：默认角色"出海合伙人"（低多边形小人，男女外观二选一，进游戏时选一次，之后可在总部大楼更衣镜处改）；角色有走 / 跑 / 待机 / 交互（伸手）四种动画。
- **3D-014 移动**：桌面 WASD 移动 + 鼠标视角；移动端左下虚拟摇杆移动 + 右侧拖动转视角；步行速度 4.5 米/秒，按住 Shift（或摇杆推满）跑 7 米/秒；禁止穿墙、穿人、穿货箱（碰撞盒以模型外轮廓为准）。
- **3D-015 相机**：跟随相机，距角色 6 米、俯仰角 18°、FOV 55°；室内自动拉近到 4 米；相机不得穿墙（遇墙自动拉近到墙前）；鼠标滚轮 / 双指缩放可在 4–8 米内调距。
- **3D-016 交互通用规则**：靠近交互点 2.5 米内 → 该物体描边高亮 + 头顶出现提示（桌面"按 E"、移动端"点一下"）；按下后执行交互（对话 / 打开控制台 / 拿起商品）；交互进行中角色锁定在原地（防边走边操作导致状态错乱）；Esc / 返回键关闭当前交互（不退出世界）。
- **3D-017 交互失败反馈**：对未解锁的门 / 未到步骤的物体按交互 → 弹一句世界内提示（NPC 气泡或门上浮字），例如"先去选品展厅挑一件商品"，不得静默无反应。

## §3 七个室内世界（逐一讲明）

> 通用：每个世界 = 一栋建筑内部；入口 = 总部大楼一楼对应的门；出口 = 原路门（回 Hub）或完成后的传送点（直达下一个世界的门前，带推门过场）；世界内禁止跳关（未完成本世界，下一世界的门保持上锁）。

### 3.1 W1 选品展厅（对应：选商品、选供应商）

- **3D-018 场景内容**：展厅 1 层；货架 3 排（按商品品类分区：生活方式 / 美妆个护 / 3C / 家居 / 服饰 / 食品等现有商品池）；每个商品一个带模型的展位 + 展位前小立牌（商品名、参考价、成本、建议市场适配度星级）；供应商展位 3 个（标准 / 快速 / 工厂，各站一位供应商 NPC）。
- **3D-019 交互点① 拿起商品**：走近展位 → 提示 → 交互 → 商品模型放大到角色手上 + 弹出商品信息板（世界内屏幕样式：商品名、成本、参考价、适配市场、供应商交期）；点"就它了" = 选中该商品（对应原选商品操作），点"放回去" = 取消；一次只能手持 1 件，选中后该展位亮绿灯。
- **3D-020 交互点② 供应商 NPC 对话**：走近供应商 NPC → 对话框（见 §5）：他会报出自己的条件（单价、起订量、交期），选项只有"选他" / "再看看"；选中后其展位亮绿灯，其余两家变灰（可反悔重选，未确认前随时换）。
- **3D-021 完成条件**：商品已选 + 供应商已选 → 展厅出口绿灯亮 + 任务句更新；完成条件与原环节一致，不新增。
- **3D-022 教学（首轮）**：接待员 NPC 在门口说一句话（见 §5），地面光柱指向第一个推荐商品展位（推荐 = 原 REQ-047 推荐默认对应的商品）。

### 3.2 W2 定价财务室（对应：定价、备货量）

- **3D-023 场景内容**：一间财务室；中央一张控制台（价格牌 + 备货滑杆做成控制台上的拨盘与拉杆，世界内可视化）；墙角堆货箱；墙面一块"成本板"（显示：单件成本、运费、平台费、关税估算，随价格实时变）。
- **3D-024 交互点① 价格拨盘**：走近控制台 → 拨盘界面（世界内屏幕样式）：拨动改价，成本板同步变，另有一行红字预警（当售价 ≥ 参考价 1.5 倍时出现"定太贵了，退货会变多"，对应 REQ-049 高价退款机制的教学提示）；价格确认 = 原定价操作。
- **3D-025 交互点② 备货拉杆**：拉杆分三档（小批验证 / 规模试销 / 溢价定位，对应原三档备货方案）；每档货箱数量实时变化：小批 4 摞、规模 8 摞、溢价 12 摞（每摞 = 100 件的视觉单位，超过 12 摞不再增加摞数、只加高）；备货确认 = 原备货操作。
- **3D-026 完成条件**：价格已确认 + 备货档已确认 → 出口绿灯亮。
- **3D-027 防呆**：价格未确认时拉备货杆可以看效果，但不计入确认；两个都确认后控制台变绿、不可再改（与原环节"确认后锁定"一致）。

### 3.3 W3 商品页工作室（对应：上架、标题主图风格）

- **3D-028 场景内容**：一间工作室；正面一面大屏 = 商品页预览（标题、主图、价格、评分星）；两侧两个工作台：标题台、主图台；大屏右上角实时显示上架分（0–100，与原上架分一致）。
- **3D-029 交互点① 标题台**：交互 → 标题选项（世界内屏幕样式，选项 = 原标题选项池）；选后大屏标题同步变、分同步变。
- **3D-030 交互点② 主图台**：交互 → 主图风格选项（品类风格池）；选后大屏主图同步变；品类匹配时大屏边缘闪绿光 + 分数 +3 提示（对应原品类匹配加分）。
- **3D-031 完成条件**：标题已选 + 主图已选 → 点大屏下方的"发布上架"按钮（世界内按钮）= 原上架确认；发布后大屏显示"已上架 + 分数"，出口绿灯亮。

### 3.4 W4 直播间 / 推广室（对应：选推广渠道 + 二级决策）

- **3D-032 场景结构**：一间大推广厅，内分三个隔间（内容号直播间 / 广告投流室 / 达人会客室），隔间门上方挂渠道名与预算牌（内容 $900 / 广告 $2,200 / 达人 $1,800，对应 REQ-049 校准后预算）；一次只能进一个隔间，选定后其余两间隔间门变灰（可反悔重选，未确认前随时换）。
- **3D-033 内容号直播间**：主播小人站在镜头前；交互点 = 选题板（原二级决策：测评 / 开箱 / 教程三选一）；选后主播开始播（小动画），预算牌显示 $900 已花。
- **3D-034 广告投流室**：一面投流大屏（预算条从 $2,200 往下烧的动画）；交互点 = 素材方向板（原二级决策选项）；选后大屏开始跑数字。
- **3D-035 达人会客室**：三位达人 NPC 站成一排（对应原达人三选一）；走近任意一位 → 对话框（报价、粉丝量、佣金 8%）；选一位 → 其余两位离场（小动画走出门）。
- **3D-036 完成条件**：渠道已选 + 二级决策已选 → 出口绿灯亮；完成前可换渠道，换后预算牌与隔间状态同步重置。

### 3.5 W5 物流仓（对应：选履约、头程）

- **3D-037 场景内容**：一间仓库；货箱堆（数量 = W2 确认的备货量视觉单位）；三条出货线（经济专线 / 标准履约 / 加急履约，各一条传送带）；仓外停着飞机、货车、货轮模型（头程选项的可视化）。
- **3D-038 交互点① 履约传送带**：走近一条传送带 → 交互 → 该带亮起 + 显示本档条件（运费/单、时效天数、退款率：经济 $3/8 天/8%、标准 $5/4 天/3%、加急 $6.5/2 天/0%，对应校准后数值）；选定 = 原履约选择。
- **3D-039 交互点② 头程航线（第 2 轮起）**：第 1 轮无此交互（默认海空联运，不出现选项）；第 2 轮起仓外三个模型可交互（空运 / 海空联运 / 海运），选后对应模型亮灯、其余变灰；选定 = 原头程选择。
- **3D-040 完成条件**：履约已选（+ 第 2 轮起头程已选）→ 出口绿灯亮；选定后货箱开始上带（小动画）表示"已发货"。

### 3.6 W6 财报结算厅（对应：结算、看三大表）

- **3D-041 场景内容**：一间会议室；正面三面大屏（利润表 / 资产负债表 / 现金流量表，对应 REQ-048 三大表）；中央一张长桌；墙面一条本轮现金曲线（对应视频底部曲线）。
- **3D-042 交互点① 大屏**：走近任一大屏 → 该屏放大 + 白话注释逐行出现（与 REQ-048 注释一致）；利润表屏可切换"瀑布图"视图（收入 → 各项扣费 → 利润，一步步掉下来）。
- **3D-043 交互点② 结算按钮**：长桌中央一个"结算本轮"按钮（世界内按钮）；按下 → 结算动画（数字滚动、曲线定格）→ 显示本轮结果（利润、留单、是否达标）→ 出口绿灯亮；结算后三大屏锁定为本轮最终版（不可再改）。
- **3D-044 教学点可视化**：现金流为负时，会议室灯光变红 + 墙面现金曲线标红段 + 接待员 NPC（或结算厅讲解员）说一句话："账上赚钱，手里没钱，也会死"（对应内测公告钩子与 REQ-048"利润≠现金"教学）。
- **3D-045 完成条件**：已结算 → 本轮结束 → 回 Hub（下一轮开始时，七扇门状态按新轮次重置，未解锁的重新上锁）。

### 3.7 W7 荣誉墙展厅（对应：成就、共建者徽章）

- **3D-046 场景内容**：一间展厅；墙面挂已获得的成就徽章（对应 REQ-040 成就馆 28 个）与共建者徽章；中央一个共建者信箱（NPC 造型信箱）。
- **3D-047 交互点① 徽章墙**：走近任一徽章 → 显示获得条件与获得时间；未获得的显示灰色轮廓 + 条件（不剧透数值细节，只给方向）。
- **3D-048 交互点② 共建者信箱**：交互 → 进入共建者专线（原 REQ-045 的 3 题 + 选填文字框，全部做成与 NPC 对话的样式，题干与选项文案不变）；提交后信箱冒金光 + 奖励到账提示（+50 建设点，徽章上墙动画）。
- **3D-049 常驻规则**：荣誉墙展厅常驻开放（不按轮次上锁）；第 1 轮结算后，任务标记首次指向这里（引导玩家交反馈）。

## §4 NPC 与对话系统

- **3D-050 NPC 清单（全游戏共 8 类）**：接待员（总部大楼门口 + 结算厅讲解员兼任）/ 供应商×3（标准 / 快速 / 工厂）/ 达人×3 / 主播×1 / 共建者信箱（NPC 化信箱）/ 帮助终端（机器 NPC）/ 路人 NPC（Hub 街区装饰，不可对话，只走动与闲聊气泡）。
- **3D-051 对话框规范**：底部对话框（宝可梦式）：NPC 名字 + 立绘小头像 + 正文；正文大白话，每句 ≤30 字；选项以按钮列出（≤3 个）；对话进行中玩家不能移动；对话结束自动回原地。
- **3D-052 对话与原系统对应**：总部来电 quiz → 接待员对话（题干、选项、答后回应文案不变）；共建者专线 → 共建者信箱对话（3 题 + 选填框不变）；HELP 逻辑卡 → 帮助终端对话（五张卡内容不变，分条说）。
- **3D-053 NPC 状态**：已对话过的 NPC 头顶不再冒感叹号；未对话的关键 NPC（接待员、当前世界供应商）头顶有金色感叹号；路人 NPC 无感叹号。

## §5 任务指引系统（防迷路是生死线）

- **3D-054 地面光柱**：当前任务目标位置立一根金色光柱（高 8 米、直径 1.5 米、半透明），玩家 20 米外可见；支线（荣誉墙、帮助终端）用蓝色光柱。
- **3D-055 HUD 任务句**：屏幕顶部中央一句话任务目标（如"去选品展厅挑 1 件商品"），完成即时换下一句；不得同时显示两句以上。
- **3D-056 小地图标记**：见 3D-012；当前任务在小地图上为金色感叹号，且带方向箭头（指向目标相对方位）。
- **3D-057 完成反馈**：每完成一个世界：金光一闪 + 一声提示音 + 出口绿灯亮 + 任务句更新；不得用纯文字 toast 代替。
- **3D-058 迷路兜底**：玩家 60 秒无有效交互（没碰任何交互点）→ 接待员 NPC 通过"传呼"发一句话提示（屏幕边缘气泡，不打断移动）："去 XX，门口有金色光柱"；该提示每轮最多 2 次。

## §6 世界内屏幕（diegetic UI）规范

- **3D-059 定义**：世界内屏幕是世界里的物体（墙面大屏、控制台屏、终端屏），不是系统弹窗；玩家必须走近才能看清（5 米内自动放大到可读尺寸，离远只显示标题与关键数字）。
- **3D-060 数据来源**：所有屏幕数字全部取自引擎 state（现金、库存、订单、利润、税费），不得手写假数；屏幕刷新时机 = state 变化时即时刷新（价格拨动、选择变更时同步变）。
- **3D-061 屏幕清单**：世界地图终端屏（12 国节点与进入费）/ 成本板（W2）/ 商品页大屏（W3）/ 投流大屏（W4）/ 结算三屏（W6）/ 帮助终端屏；每块屏的标题与关键数字在 5 米外可读（字号 ≥ 世界单位 0.5 米）。
- **3D-062 系统弹窗禁令**：除存档/网络错误与支付确认外，禁止任何居中系统弹窗；所有游戏内信息必须有世界内的载体（屏幕、NPC 气泡、门上浮字、HUD 任务句）。

## §7 HUD 规范（只留四件）
