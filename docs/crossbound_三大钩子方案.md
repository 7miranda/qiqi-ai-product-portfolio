# Crossbound 三大钩子方案：出海达人认证 × 出海护照 × 跟卖者剧情

> ⚠️ **已合并（2026-10-20）**：本文件内容已融合进《crossbound复盘_缺失环节与优化方案.md》第三节（留存设计·三大钩子详细方案），后续以复盘文档为唯一权威版本。本文件仅作存档，不再更新。

> 整理日期：2026-10-20。基于 2026-10-19 复盘的钩子发散，用户圈定 3 个展开。
> 三者定位互补：**认证 = 身份钩子**（咬合北极星"留资→真实合作"），**护照 = 收集钩子**（轻量，驱动换市场），**跟卖 = 叙事钩子**（悬念+教育，联动《大卖》攻防系统）。

## 钩子一：出海达人认证（身份钩子）

### 为什么
- 游戏定位是"合作筛选器"，但目前筛选结果（玩家行为数据）对玩家不可见、无激励。认证把筛选**显性化**：玩家为了拿高段位主动证明自己，留资变成"我想赢"的结果，而不是表单。
- 段位可挂在战报上、发给 MCN 看——游戏成绩第一次有"简历价值"。

### 玩法规则
- **段位体系**（在现有等级之上叠加，不替代）：出海新手 → 出海探索者 → 出海达人 → 区域卖家之星 → 全球经营合伙人（名称可再打磨，避免和现有 LV 称号冲突）。
- **评定维度（多维，防无脑刷）**——只看利润会被"无脑最优解"刷穿，段位必须多维：
  1. **盈利力**：最佳单轮利润 + 近 5 轮平均利润
  2. **稳定性**：退款率、是否出现过亏损轮
  3. **市场广度**：出海护照进度（见钩子二）
  4. **认知水平**：总部来电 quiz 正确率（呼应复盘§八"游戏即面试"）
- **认证卡**：达标后生成一张可分享的认证卡（图片），含段位、关键战绩（最高单轮利润/擅长市场/选品胜率/quiz 正确率）、专属编号。
- **留资咬合点**：认证卡"领取实体权益"时留资——如金牌段位可申请"样品包/选品会邀约"，留资动作包装成领奖，不是填表。
- **真实合作咬合**：段位 = 合作优先级（高段位优先对接真实商品/样品），规则在游戏内明示，让玩家知道"玩得好有什么用"。

### UI 落点
- "我的成长"页新增"我的认证"区块（段位进度 + 四维雷达）。
- 战报分享卡右上角带段位徽章。
- 升级瞬间全屏仪式感动画（段位晋升是全游戏最高光时刻，要做足）。

### 实现成本
- 中等：复用现有等级/经验数据，新增评定计算 + 认证卡生成（可复用战报图片生成管线）。不改经济公式。

## 钩子二：出海护照（收集钩子）

### 为什么
- 现状痛点：玩家只会守着一个最优市场反复刷（市场间无真实差异+无换市场动机）。护照给"去新国家"一个**牵引式**理由（符合初版原则：别做墙、做灯）。
- 12 个国家天然就是一本护照，收集癖永不过时；实现成本三者最低。

### 玩法规则
- **盖章条件**：在一个国家完成一轮且达标（未退款订单 ≥ 本轮目标 且 利润 > 0）→ 盖该国印章。
- **印章分级**：铜章（达标）/ 银章（单轮利润 > $5,000）/ 金章（单轮利润 > $10,000 或零退款轮）。
- **区域收集奖励**：集齐一个区域（如欧洲：伦敦/柏林/巴黎/阿姆斯特丹）→ 解锁区域称号 + 建设点奖励；12 国全金章 → 终极称号"环球经营者"。
- **与认证咬合**：护照进度是认证"市场广度"维度的输入（见钩子一）。
- **新国家首次进入**：给"首入奖励"（少量建设点），并弹该国真实小知识卡（市场偏好/一句当地问候语）——收集+教育二合一。

### UI 落点
- 新增"出海护照"页（护照本样式，12 页签证页，未盖章的国家是灰色虚线框）。
- 第 1 关选市场时，已盖章国家显示印章角标，未盖章的显示"未解锁印章"小字提示（牵引，非强制）。
- 盖章瞬间盖章动画（"啪"一下，音效可选）。

### 实现成本
- 低：纯前端状态 + UI，零公式改动。可最先上线验证收集驱动。

## 钩子三：跟卖者剧情（叙事钩子）

### 为什么
- 跟卖是跨境电商最真实、最有张力的痛点（呼应《大卖》五大系统中的"跟卖攻防"）。crossbound 目前全程无冲突、无对手，玩家打的都是"自己和公式"，叙事张力为零。
- 剧情里埋教育：**商标前置**——第 1 轮 quiz 教过商标，第 N 轮跟卖来了才发现"没注册商标投诉不了"，这种"伏笔回收"是最有效的教学。

### 玩法规则（三幕剧）
- **触发条件**：单轮利润 > $6,000，或同一商品连续 2 轮爆单（销量达库存上限）→ 下一轮第 4 关后触发"总部来电：你的爆款被跟卖了"。
- **第一幕·发现**：同款低价跟卖出现，该商品转化 −30%（或被迫进入价格战），总部来电给出情报（对方价格/销量）。
- **第二幕·应对（四选一，各有代价）**：
  1. **降价迎战**：保销量，利润 −X%（考验毛利空间）
  2. **投诉下架**：需已注册该商品商标（未注册则此选项灰置，并提示"第 1 轮就提醒过你"——伏笔回收）；成功率与上架质量分（REQ-006）挂钩
  3. **差异化升级**：花一笔钱升级包装/套装，转化回升且售价可上浮（品牌路线）
  4. **换市场避让**：放弃当前市场，下轮强制换市场（与护照钩子咬合：正好去盖新章）
- **第三幕·结算**：按选择给出结果文案 + 数值结算；剧情结果记入"经营档案"，认证评定可引用（如"成功处理过跟卖"加分）。
- **可复现**：跟卖者有名字和人设（如"影子卖家老 K"），后续轮次可能再来（升级版：他也成长），形成长期对手线。

### 与现有系统的关系
- 依赖事件系统（PRD v2 池 REQ-026）——跟卖剧情可作为事件系统的**首发内容**，先验证叙事钩子再扩事件库。
- 与 REQ-006（上架关）咬合：上架质量分影响投诉成功率，上架环节从此有了长期价值。
- 与《大卖》联动：crossbound 做轻量剧情版，《大卖》做完整攻防版，叙事宇宙互通（同一个"老 K"可以出现在两款游戏里）。

### 实现成本
- 高（三者最高）：需事件触发框架 + 分支文案 + 数值注入点。建议放最后，先用护照+认证验证钩子体系。

## 三者组合关系

```
出海护照（去更多国家） ──┐
                          ├─→ 认证四维评定 ─→ 段位 ─→ 留资/真实合作（北极星）
跟卖剧情（处理危机） ────┘        ↑
总部来电 quiz（答题） ────────────┘
```

- 护照和跟卖是"行为发生器"，认证是"价值结算器"：玩家为了段位去盖章、去打跟卖者，段位把行为翻译成合作优先级。
- 三者共享一个原则：**牵引代替管制**——没有一个钩子是靠"不解锁不让玩"工作的。

## 落地顺序建议

| 顺序 | 钩子 | 理由 |
|---|---|---|
| 1 | 出海护照 | 成本最低，纯前端；先验证"收集牵引"是否有效 |
| 2 | 出海达人认证 | 复用现有等级数据；咬合北极星，需要商务侧确认权益（样品包/邀约）能给什么 |
| 3 | 跟卖者剧情 | 依赖事件系统；文案量大；作为 v2 的叙事招牌 |

> 待确认（商务侧）：认证权益清单——样品包、选品会邀约、MCN 面试直通，哪些真实可给？钩子一的强度取决于这个清单的真实成色。
