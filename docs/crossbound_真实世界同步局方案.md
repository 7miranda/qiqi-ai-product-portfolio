# crossbound 真实世界同步局 · 方案

> 2026-10-20 用户圈定为爆点主攻方向（调研报告中的战报卡/称号/图鉴等机制降级为"卫生件"，该做但不当爆点）。
> 一句话：**别人玩的是假市场，你玩的是这周真实发生的世界。每周一局，全网同题。**

## 1. 为什么是它

- **抄不走**：封闭世界经营游戏满地都是；"用真实新闻当题面"的游戏，题面每周自动更新——内容本身就是护城河。
- **同题 = 天然话题**：Wordle 证明过"全网同一题 + 固定节奏 + 结果可晒"是顶级传播结构。所有人玩同一局，成绩才可比、才值得讨论（"黑五周你打了多少？"）。
- **教育性拉满**：我们的北极星是"玩懂跨境"。用真实事件教学，比虚构参数有说服力得多——达人玩完记住的是"关税真涨了会怎样"，不是"游戏里设了个数字"。
- **自带回访理由**：不用连胜/签到逼回来——世界每周都在变，玩家是被新闻拉回来的。

## 2. 玩法结构：双轨制

| | 自由局（现有模式） | 同步局（新增·正赛） |
|---|---|---|
| 题面 | 固定参数、随机种子 | **本周真实事件包**（全网同一份） |
| 节奏 | 随时玩、易通关 | 每周一期（周一开局、周日结算） |
| 定位 | 练手 + 教学（保持"通关很容易"） | 挑战 + 排名 + 晒图 |
| 产出 | 经验/建设点 | 周榜名次、事件称号、认证加分（REQ-034） |

自由局不动（守住"易通关"的新手体验），同步局是每周的事件——**难度和张力只放在同步局里**，两边不打架。

## 3. 一局长什么样（玩家视角）

1. **周一开局**：打开游戏先看到「本周世界」——3~5 张真实事件卡，每张 = 真实新闻标题 + 一句人话解释 + 它在本局的影响：
   - 📰「美国对华小包关税上调」→ 本局美国市场关税 8% → 18%
   - 📰「斋月临近，中东家居需求走高」→ 本局中东市场家居品类需求 ×1.4
   - 📰「红海绕行，欧洲线运费三连涨」→ 本局欧洲市场运费 +$2/单、时效 +3 天
   - 每张卡附**原文链接**（点出去能看到真新闻）
2. **经营 6 关**：在被真实事件改过的参数下做决策——绕开美国？押注中东？提前备货避运费高峰？决策第一次有了"现实依据"。
3. **周日结算**：三件事——
   - 你的成绩 + **同题排名**（垂类小榜："家居达人里你第 7"）
   - **事件复盘**：「现实里后来怎么样了」——本周真实后续（运费真的回落了/新规真的执行了），模拟与现实对照，这是别家给不了的教学闭环
   - 战报卡自带事件标签（「黑五周 · 第 7 名」），晒出去自带话题

## 4. 事件包规格（给 Codex 的数据结构）

每周一份 JSON 配置，游戏只管读和渲染，**不需要为每周内容改代码**：

```
{
  week: "2026-W43",
  theme: "黑五前哨周",
  events: [
    { id, type: 政策|物流|市场|平台,
      title: "新闻标题（真实）", source_url: "原文链接",
      explain: "一句话人话解释",
      effects: { marketId?, category?, tariffDelta?, demandMul?, freightDelta?, leadDaysDelta? },
      teaching: "总部来电 quiz 出题点（一句话）" }
  ],
  seed: 本周统一随机种子（保证同题公平）
}
```

事件类型库（举例，持续积累）：
- **政策类**：关税调整、海关严查、平台佣金/退货新规、某国电商税
- **物流类**：运费涨跌、港口拥堵、航线中断、旺季附加费
- **市场类**：大促节点（黑五/网一/斋月/双十一/开斋）、汇率大幅波动、某品类在 TikTok 突然爆火
- **平台类**：TikTok Shop / 亚马逊 / Temu 的规则与流量政策变化

## 5. 内容从哪来（三档，按投入递增）

| 档 | 做法 | 每周成本 | 何时上 |
|---|---|---|---|
| 手工档 | 人工挑 3~5 条新闻，填事件包模板 | 1~2 小时 | MVP 先跑 2~3 期验证 |
| **LLM 草稿档（推荐主线）** | 脚本抓跨境新闻 → LLM 生成事件卡草稿（标题/人话/参数建议/教学点）→ **人只审核改数字** → 发布 JSON | 审 20~30 分钟 | 第 2 步 |
| 自动档 | 汇率（免费 API）、大促日历（固定表）自动生效；新闻仍走 LLM 草稿档 | 近零边际 | 第 3 步 |

关键原则：**参数影响永远由人定版**（LLM 只给建议值）——游戏参数是教学口径，不能让模型乱改。

## 6. 与现有系统的关系（不另起炉灶）

- **REQ-026 事件系统** → 同步局就是它的"真实数据源版"：原虚构事件池降为自由局用，同步局用真实事件包
- **REQ-011 跨轮波动** → 波动从"随机数"变"真实数据"：有出处、可复盘，比随机扰动更可信
- **REQ-003 关税 / REQ-009 市场系数** → 在同步局里第一次有了动态数据源（不再是写死的数）
- **总部来电 quiz** → 直接用本周事件出题（"美国关税刚涨，你的美国单怎么办？"），题目每周自动换
- **REQ-034 认证 / REQ-040 成就馆** → 同步局名次与事件称号（如「黑五幸存者」）进认证加分与成就馆
- **垂类小榜**（调研机制 #6）→ 同步局周榜就是它的载体，不用单独做
