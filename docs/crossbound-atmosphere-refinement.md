# 连续空间、平面按钮与流程清理

日期：2026-10-29。基于 main `1001ae6`。

## 反馈与根因

用户指出深黑背景误入部分区域、按钮有不需要的3D凸起、空间感不足、首页流程出现多余线条。

- 首页原生 `.campaign`、`.arrival-portal` 和 `.portal-shade` 仍使用 `#03080b`。此前只有经营态有环境底色，首页区块间隙直接露黑。
- 流程背景叠加多层高不透明度深色遮罩，底部几乎完全挡住场景。
- 旧 CTA、导航和次按钮用凸起渐变、底边阴影和位移模拟厚度。
- 流程区边缘、完成说明、标题栏和折叠摘要重复叠线；首屏快捷入口顶线还穿过球面。

## 修正

- 首页共用一层连续厂区后景，区块底改透光层；场景中的建筑、远景与地面反射贯穿区块间隙。
- 玻璃与数据槽统一为透光钢蓝，不再分别使用近黑底。
- CTA、导航、筛选、页签和返回控件平面化；保留清晰边界、选中颜色、勾选、键盘焦点和禁用状态。
- 移除上述重复装饰线，保留有数据或状态含义的图表、进度和选择标识。
- 首页地球的近黑贴图色改为 `#1c3b50`。通过生成器在 `eG` 中定点修改，原生透明渲染器、几何、拖动和动画保持一致。
- 园区模型、镜头、建筑和经营逻辑保持一致。经营页头与脚部使用同一钢蓝材质。

- 7份 CSS 解析、背景资产路径、双入口内容版本与差异检查通过。
- 桌面、390px、320px 实图检查。320px 工作室宽度与视口一致，滚动后底栏 bottom=844；主按钮 background-image=none，Tab焦点可见。
