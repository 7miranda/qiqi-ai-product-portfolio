# Crossbound 前端文案优化：表达更正清单

> 整理日期：2026-10-19。基于线上版全量 UI 字符串逐条审查。
> 总原则：这是个游戏，不是 ERP。玩家（国内达人 + 有一点经验的小卖家）要的是**一眼懂、有代入、不出戏**。

---

## 一、术语：先分三类，再定词表（P0）

> 2026-10-19 修正：第一版把"有细分含义"的词也硬压成了一个，欠妥。正确做法是分三类——**纯同义词才统一，动作/名称/结果态按场景各归其位，真有不同含义的保持区分**。

全站存在**三套关卡命名**：代码 iS（选择市场/确定产品线/定价与备货/建立获客渠道/完成跨境交付/复盘与扩张）、新版 $z（销售市场/主打商品/定价备货/商品推广/发货收款/下一轮计划）、底部进度条（选择市场/选择商品/定价备货/推广商品/发货收款/安排下轮）。**关卡名**全站统一为一套（建议用底部进度条那套，最口语）。

### A 类：纯同义词，直接统一

| 现状并存 | 统一为 |
|---|---|
| 到访 / 访问次数 | 访客 |
| 选择商品 / 选择经营商品 | 选择商品 |
| 推广商品 / 商品推广 | 推广商品 |
| 查看本轮经营结果 / 看看本轮结果 / 查看本轮战报 | 本轮战报 |
| 未退款订单 / 没有退款的单 | 未退款 X 单 |
| 获客预算 / 推广预算 | 推广预算（达人懂"推广"，未必懂"获客"） |
| 余货 | 剩货（"余货"生硬，全文 10+ 处） |

### B 类：动作 vs 名称 vs 结果态，按场景区分，不要硬统一

| 词 | 场景分工 |
|---|---|
| 达人合作 / 联系达人 | **保留两者**："达人合作"是渠道名称（名词），"联系达人"是按钮动作（动词），各归其位 |
| 本轮赚到 / 贡献利润 | **分层使用**：玩家界面一律"本轮赚到"；"贡献利润"退到"？"逻辑卡和账本里当财务术语 |
| 推广预算 / 推广费 | "推广预算"是计划数（滑块），"推广费"是结算行里的实际花费，保留区分 |
| 主打商品 / 选择商品 | 关卡名统一"选择商品"；选定之后称"本轮主打商品"（结果态，不冲突） |
| 安排下轮 / 复盘与扩张 | 关卡名统一"安排下轮"；关卡内的大标题可用"复盘与扩张"（这关确实包含复盘+扩张决策，描述性标题没问题） |
| 建立获客渠道 / 完成跨境交付 | 这两个**直接弃用**：前者 overstate 了（实际只是选推广方式+预算），后者是书面语；分别用"推广商品""发货收款" |

### C 类：真有不同含义，保持区分（第一版错压的部分）

| 词 | 为什么不能合并 |
|---|---|
| 曝光 / 点击 / 访客 | 这是**漏斗三阶段**，不是同义词。A/B 任务里的"10,000 曝光 → 500 点击 → 5 单"是对的，别动 |
| 库存 / 剩货 | "库存"是总称（含在售），"剩货"特指本轮没卖完带到下轮的。第一版写"剩货（或库存）"是错的 |
| 基地 / 公司总部 | 这是**设计决策**，不是文案问题："基地"是养成系 fantasy（我的海外基地），"公司总部"是企业系。先定想要哪个 fantasy，再统一 |
| 履约 / 发货 | "履约"含义更广（含仓储配送退货），第 5 关实际只是选快递档，用"发货"更准；但"履约中心"作为设施名可以保留"履约" |
| 经营现金 → 出海基金 | 这是达人视角的**改名**（见第五部分），不是同义词统一 |

## 二、黑话与论文腔：玩家看不懂 / 出戏（P1）

| 原文 | 问题 | 建议 |
|---|---|---|
| 8 天时效，**本模型**退款比例 8% | "本模型"像论文 | 8 天送达，退款率约 8% |
| **模拟**到访 / **模拟**运费系数 / **模拟**平台费 / **虚构模型** | "模拟"前缀泛滥，"虚构"出戏 | "虚构模型"→"练习模式"；"模拟平台费"→直接"平台费"，页脚统一声明一次"是模拟数据"即可 |
| 需求 = floor(到访 × 2.5% × …) | **floor 是程序员语言** | 取整（"向下取整"） |
| **计佣**范围与退款**口径** | 黑话 | 算佣金的范围与退款标准 |
| 抢到**截单**也不能修复错误地址 | 黑话 | 赶上截止揽收时间 |
| 避免变成**退件** | 黑话 | 退回件 |
| 7 天补货**时滞** | 书面 | 延迟 / 需要 7 天 |
| **履约**中心发来急件 | 黑话（第 5 关场景） | 发货中心（"履约中心"作为设施名可保留） |

## 三、拗口长句与双重否定（P2，逐条改）

| 原文 | 建议 |
|---|---|
| 扩张决策前，收入扣除已售货成本、获客、履约与本轮市场运营费用后仍有结余。 | 扣掉货款、推广、运费这些成本，这轮还赚钱。 |
| 本关及之后的钱、货与结果已撤回，先前选择保持相同，可公平比较新方案。 | 已回到本关开始前的状态，换个方案再试一次吧。 |
| 已回到上一轮开始前的真实现金与库存，同时撤回对应收入和费用。你可以重做方案；这里没有新增资金。 | 已回到上轮开始前的现金和库存，可以重新安排了。（"真实"二字多余） |
| 下一轮额外到访不是保证成交。 | 下轮多来的访客，不一定都会下单。 |
| 建设点用于游戏建设，经营现金另行结算。 | 建设点只用来升级公司，和现金分开算。 |
| 经营现金与游戏奖励分开记录 · 金额、需求与费率为公司设定 | 现金和奖励分开记；金额和费率是练习用的设定值。 |
| 本轮模拟收入未覆盖全部已计费用。 | 这轮的收入还没盖住成本。 |
| 达标不会再额外送一笔现金。 | 达标没有额外现金奖励。（别用双重否定） |
| 六关完成，目标还没全部达到；可以调整方案再算一次。 | 6 关走完了，目标还差一点，调调方案再来一次。（"再算一次"太干） |
| 已交给系统分享。是否发出，由你在分享窗口中决定。 | 已打开分享，发不发由你决定。 |
| 当前浏览器不能调用系统分享，可以保存图片或复制文字。 | 这个浏览器不支持直接分享，可以保存图片或复制文字。（别"调用系统"） |
| 经验和建设点已记下。接下来可以建设基地、重做经营方案，或带着现金与余货开下一轮。 | 经验和建设点已到账。接下来可以升级公司、重做方案，或带着现金和剩货开下一轮。（"已记下"太随意） |
| 本轮已发货，还没安排下一轮。后续如果追加投入，这轮利润会继续变化。 | 本轮已结算。去"安排下轮"看看还能怎么投入。（"追加投入"指代不明） |
| 经验让角色升级；建设点用来建基地。它们都不能换成经营现金。 | 经验用来升级，建设点用来建公司，都不能换成现金。（"角色"一词别处没出现过，删掉） |

## 四、缺游戏感：太平、太干（P2）

- "查看本轮经营结果" → "看看这轮战绩"（和"战报"体系统一）。
- "继续我的生意" vs "开始第一笔生意" → "生意/公司"混用，全站统一一个（建议"公司"，和"我的跨境公司"对齐）。
- 开场三行"让好产品，卖向全球 / 选商品、找达人，把货卖到海外 / 卖出第一单，再把公司一步步做大"——写得不错，保留。但"找达人"可以强化（目标用户就是达人）。
- "游戏给你练习机会；这里的订单、费率和合作结果是模拟的。" → "这里练手不花钱，订单和费率都是模拟的，别怕试错。"（把"练习机会"说教感去掉，顺带安抚新手）

## 五、达人视角专项（结合"帮达人和商品一起出海"定位）

如果目标用户是达人，以下表达建议整体替换（P1）：

| 现在 | 建议 | 理由 |
|---|---|---|
| 经营现金 | 出海基金 | 达人语境，"经营"太 B 端 |
| 获客预算 | 推广预算 | 达人天天说"投流/推广"，不说"获客" |
| 贡献利润 | 本轮赚到 | 大白话；财务术语退到"？"卡里 |
| 履约中心 | 发货中心 | 同上 |
| 到访 | 访客 | "访客"比"到访"更像人 |
| 总部来电 | **保留** | 有剧情感，是全站写得最好的钩子（"旗舰产品，卡在下单之前。"） |

## 六、做得好的：保留，不要改

- "240 件是目标覆盖量，不是新增采购量。你已有 180 件可用，再买 240 件会额外多压 180 件；先减去可用库存。"——具体、场景化，教学的天花板。
- "先看点击后的成交和成本，别只看点击多就追加预算。"——口语化教学。
- "有自然成交不等于获得了投放权限。"——干脆。
- "10,000 曝光 → 500 点击 → 5 单"——漏斗可视化，比文字强。
- "旗舰产品，卡在下单之前。"——悬念感，全站最佳钩子。
- 总部来电的 quiz 任务（A/B 素材二选一、佣金计算题）——案例式教学，适合达人。

## 七、执行建议

1. **P0 先出词表**：第一部分 A/B/C 三类定稿。A 类全局替换；B 类按场景各归其位；C 类先定设计决策（基地 vs 公司总部二选一）。
2. **P1 黑话与达人视角**：第二、五部分一起改，都是查找替换级工作量。
3. **P2 长句改写**：第三、四部分逐条过，需要文案 sense，建议找一位有游戏文案经验的人顺一遍（或拿给 2–3 个达人朋友读一遍，凡是读两遍才懂的都改）。
4. **红线**：以后新增文案，先过三问——达人一眼懂吗？有代入感吗？和词表一致吗？
