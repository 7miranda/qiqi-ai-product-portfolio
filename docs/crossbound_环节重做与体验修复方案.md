## 1. 诊断总览：大框架没错，乱在四个结构上

- **乘数叠加，无法归因**：到访、转化、需求每环都是五六个系数相乘，正确选择与错误选择的结果差可能还不如一次随机波动。玩家复盘推不出"哪一步错了"，只能觉得乱。
- **子决策藏在父步骤里**：平台卡在市场步、上架塞在推广步、头程塞在定价步。玩家以为做 6 个决定，实际做 15 个，还不知道。
- **时钟不同步**：目标阶梯线性涨、大卖季 3 轮一循环、事件 45% 随机、成功招跟卖——四个节奏各走各的。
- **成长系统各说各话**：目标、金银铜、四维分、等级、建设点、成就全堆在结算页。
- **视觉与交互的毛病**：卡片全是同一套 `.v2-panel`，字号 11–13px 一片平，没有视觉焦点；每屏主行动不唯一（01/02/03 + 3 个 tab + 2 个返回）；11px 的次要文字（#8da9b2 / #85a4b0）在深底上对比不足；知识全塞在决策前，折叠区制造"不知道看不看"的焦虑。

## 2. 总原则（7 条，后面每项都按它验收）

1. **一步 ≤3 个决策**，多余的降级为"高级选项"折叠或移到别的步。
2. **一屏一主行动**：主按钮只有一个实心绿钮，文案是动词（"确认定价"不是"下一步"）。
3. **数字可算**：每个系数在决策时可见或可推导；看不见的系数不许超过 ±30% 的影响。
4. **运气 < 技术**：任何随机因子的波动范围不得大于正确选择的收益。
5. **学在事后**：知识放在结算复盘（后果→原因），不在决策前堆文字。
6. **失败可复盘，不螺旋**：失败不涨目标、不扣成长，只给原因和再来一次。
7. **单模式 2.5D**：双模式废止（见 §3），一套代码、一个模式。

## 3. 融合方案：2.5D 总部一图到底（取代双模式与 walkable 3D）

用户定版方向（她本人提出"做成一个不那么 3D 的 2D"）：**不要双模式，不要行走化身，不要跟随镜头。**

- **一张固定斜视总部地图，一图到底**：美术可带斜 45° 立体感，但交互是纯 2D 点按——无 WASD、无镜头跟随、无旋转。晕的根源（连续镜头运动）全部砍掉。进度用地图高亮 + 当前房间旗标 + 已完成打勾表示，取代 01–06 文字步骤条。
- **点房间进全屏场景，每步专属场景、专属交互，禁用统一弹窗模板**：定价室是大黑板 + 拨盘；推广室是三块屏幕选渠道；商品页工作室是货架 + 编辑台；履约步是三条传送带；结算厅是一张结算桌。验收红线：**同一个绿色弹窗模板复用 = 不合格**。
- **W1/W2/W5 改造，不推倒**：W1 展厅（商品实物 + 0.4 秒选中动画 + 绿圈放大保留）；W2 定价室补齐精细调价，**不再回 2D 面板调价**（现 W2 只有拉杆选档，精细调价走 2D 面板，是换皮残留，必须补齐）；W5 物流仓保留三条传送带 + 结算货箱动画（REQ-052）。
- **W3/W4/W6 按 2.5D 场景新建，不按 walkable 房间做**：W3 商品页工作室、W4 推广室、W6 财报结算厅各一个 2D 场景 + 专属交互；W7 荣誉墙改为成就馆常驻入口（不作为任务）。
- **切换与加载门保留**：P0.1 已验证的加载页、位置恢复、10 次刷新无闪现（1.2–2.7 秒可操作）继续有效；双模式废止后，3D↔2D 切换的已知 Bug（面板挡顶栏、落点回门口、竖屏选择页卡片 below fold）随选择页废止而消失，不再修。
- **切换动画**：房间切换 0.3 秒滑动/淡入；数字变化滚动；选中 0.4 秒飞入"已选"栏。禁止连续镜头移动。

## 4. 逐环节方案（问题 → 改法 → 验收）

### 4.1 选市场：市场不是过路费

- **问题**：进入费每轮都收，续留还收半价；平台三家差异要算账才能懂，却放在信息最少的第一步；市场容量（2 万–6 万到访，超量减半）不可见。
- **改法**：①进入费改为**首进一次、续留免费**（entered[] 已有记录，直接用它免后续费用；"续留半价"文案作废）。②平台三家在第一步用一句话差异卡并排呈现：TikTok（6% 佣金、零入驻）、Amazon（15% + 每轮 $39、转化 ×1.12）、独立站（$500 一次、流量 ×0.75）。③市场卡上显示容量条（预计到访 / 容量），超量提示"再多流量也只能算一半"。
- **验收**：玩家能说出"留下来不花钱、换市场花一次进入费"；平台三选一能说出各自代价。

### 4.2 选商品：盲选改明选

- **问题**：fit（0.8–1.35，直接乘进转化率）完全不可见；测款 $150 只能选完后测，还是 ±10% 噪声抽样。
- **改法**：①选品页显示匹配度**档位**（高/中/低，由真实 fit 映射，不给精确数字，保留探索感但不盲选）。②测款**首测免费**（教学），之后 $150；测款结果写明"抽样信号，±10% 波动，不保证订单"。③100 商品 × 12 城的 fit 表不变，不动数值。
- **验收**：玩家选品时能说出"为什么选这个组合"；首测免费只生效一次。

### 4.3 定价备货：拆！一屏只剩 3 个决策

- **问题**：一屏 10 个决策（售价、数量、供应商、供货规则、头程、账期、谈判、备战、测款、商标、贷款）；数量决策已死（批量折扣 + 全额返现 = 无脑拉满）；volume 谈判省 3% 却把 MOQ 提到 800 件以上，现金直接爆炸。
- **改法**：①本步只留**售价、数量、供应商** 3 个决策。②头程移出到履约步（§4.6）。③账期、谈判、备战、测款、商标、贷款降级为"高级选项"折叠，默认总部推荐（recommend() 已有，沿用）。④volume 谈判选 800+ 时即时提示"本单现金占用 $X，占你现金 Y%"。⑤数量张力重建：**清仓手续费 5% 定版**（STOCK_RETURN_FEE = 0.05，开关化，可调回 0）：结算返现 = 未售出成本 × 95%，5% 是"买多了的代价"，不致破产但让拉满不再免费。批量折扣（400/800/1200 档 −5/−10/−15% 再叠谈判 −3%）保留。
- **验收**：定价步一眼只有 3 个决策；拉满 1600 件时能看到手续费代价；volume 谈判有现金占用提示。

### 4.4 上架：独立成步，费用与回报都写清

- **问题**：上架塞在推广步里；费用按售价档 ×1/×1.8/×3（$89 的货付 3 倍上架费）不透明；分数→转化（分/80）、95 分奖 20% 自然流量、优化 $300 加 5 分的 ROI 全程不透明；PRD 说 006 仅剩风格选择一条，但代码里风格字段已删、matchedStyle 恒 false——文档与代码不一致。
- **改法**：①上架独立成步（从推广步拆出）。②费用写成明细行：制作费 + 跨市场本地化费（$100，复用免），不再用 ×1/×1.8/×3 的暗乘。③分数旁写换算："82 分 ≈ 转化 ×1.03"；95 分奖励写明"自然流量 +20%"。④优化 $300 按钮旁写预计回报："预计多 X 单（按上轮到访算）"，X 由引擎 preview 的 mean 算出。⑤PRD REQ-006 状态改为：风格选择已删（代码与文档对齐，不再列为剩余项）。
- **验收**：上架步能算出"这页值多少钱、值多少转化"；风格选择不再出现在任何文档的剩余项里。

### 4.5 推广：技术大于运气，二级决策合并

- **问题**：出价词 + 时段两个二级决策只值 ±10%，却多两个选择；达人匹配对口只 +15%，随机因子却 0.5–2.0（4 倍），技术被运气淹没；预算平方根曲线（翻倍只 +41% 到访，下限 300 只有基准 37%）不告诉玩家。
- **改法**：①**达人随机收窄为 0.8–1.3**，匹配加成提到 **+30%**（对口 +30%，不对口 0）。②出价词 + 时段合并为一次"打法"选择（文案合并，数值保留：低出价/均衡/高出价 × 全天/晚间/低峰的组合含义写在一行里）。③预算滑杆旁画曲线图：预算→到访曲线，标出"再加 $1000 只多 X 到访"。④渠道三选一 + 预算 + 打法 = 本步 3 个决策。站外二选一（Deal 到访 ×1.5 但 85 折 + $300；测评 +0.2 评分 + $400）保留，代价写在同一行。
- **验收**：同一方案换达人，结果波动 ≤30%；玩家能说出"对口达人值 30%"；预算曲线可见。

### 4.6 履约：独立成步，三档并排比

- **问题**：头程藏在定价步，配送三档藏在别处；到货率公式 (30−天数)/30 下限 75% 玩家算不出来；延迟件的运费已付、货不来，代价不透明。
- **改法**：①履约独立成步：配送三档并排对比卡（费用 / 时效 / 退款率 / 转化系数四项同表：经济 $3·8 天·退 8%·转化 ×0.92 / 标准 $5·4 天·退 3%·×1.0 / 加急 $6.5·2 天·退 0%·×1.1）。②头程三档并排（天数 / 单件运费 / 本轮到货率估算），到货率写白话："海运 14 天 + 供应商 X 天 = 约 Y% 本轮到货，剩下的结算时按成本退回（扣 5% 手续费）"。③延迟件运费规则写明："没到货的件，运费已付不退，货款退回"。
- **验收**：履约步一眼能比出三档；玩家能算出自己的到货率。

### 4.7 结算：瘦身 + 写明通道 + 预告前移

- **问题**：收入下轮到账、成本本轮全扣，结算时现金不够会被硬挡（"交付前现金不足"，只能当场借 12% 过桥贷）；目标出现 3 次；280/300 却"已达成"不写通道；退款四项叠加、高价双杀（>1.3 倍后退款率每 +10% 涨 12 点，上限却放到 2 倍）；评分终身平均制恢复极慢。
- **改法**：①结算页只留：本轮目标（1 次）+ **通道说明**（"靠利润 $X 过的" / "靠订单过的" / "双过，金章"）+ 钱（一行：收入、成本、利润、现金变化）+ 一句话故事 + 一个主按钮"开启下一轮"。②四维分、等级、建设点、成就全部移入总部页（成就馆），结算页只留一行链接。③现金时间线预告前移：定价步即提示"本轮成本约 $X，收入下轮到账，结算时需现金 $Y"；结算硬挡改为事前预警（定价步/推广步即算缺口，按钮置灰 + 写明差多少；过桥贷选项前置到缺口提示里，不再结算时才出现）。④退款拆解可视化：四项条形（时效 / 质量与描述 / 其他 2% / 高价预期），高价预期项旁写"售价超过 1.3 倍后，每贵 10% 退款率涨 12 点"。⑤评分说明写白话："评分是全部订单的平均分，早期差评会被后面的好评慢慢稀释"。
- **验收**：结算页一屏内能看完；目标只出现 1 次且写明通道；定价步就能看到结算现金缺口；结算不再硬挡。

### 4.8 下一轮计划：承诺讲清代价

- **问题**：扩张选项花利润换下轮流量加成（trafficBonus）或强制换市场（newMarket 会锁死上轮市场不让选），选时看不到后果；内容尾巴（10% 到访留到下轮）不讲。
- **改法**：①每个扩张选项写明：花多少钱、换来什么（流量加成具体数值）、锁什么（"选了换市场，下轮不能再选本市场"）。②内容尾巴写明："内容渠道的到访有 10% 会留到下轮"。③本步 1 个决策（选扩张项），其余是确认。
- **验收**：玩家选扩张前能说出代价和锁定后果。

### 4.9 跨轮系统：三个时钟对齐，失败不螺旋

- **问题**：目标阶梯按轮次号涨（250→300→350→400→450，失败也涨）；大卖季 3 轮循环需提前备战 $300 但无提醒；事件 45% 随机 + 成功招跟卖（遭遇越多惩罚越重，下限 55%）；热度只衰减不增长（每轮 ×0.95，引擎里无增长入口）。
- **改法**：①**目标按通过次数涨**：target = min(450, 250 + 通过次数 × 50)，失败轮目标不变；旧存档迁移：按当前通过次数重算目标（不得让老玩家一夜变难）。②大卖季提醒：备战轮提示"下下轮是收割轮，现在备战 $300 可换收割轮 +30% 到访"。③事件保底：**单事件削减封顶 20%**；跟卖反制三选一讲清结果（换市场可躲 / 投诉成功率 = 上架分 / 差异化每单 +$1.50 包装费）；随机事件池 45% 保留，但每项的"付费解除价"（$150–$200）与"不处理后果"并排写。④**热度改为连续经营加成**：同一商品连续经营每轮 +0.05（上限 1.15），换品重置为 1；删除 ×0.95 衰减（Claude 执行时若发现 UI 层已有增长逻辑，先对齐口径，以本条为准）。
- **验收**：失败后下轮目标不变；备战轮有提醒；跟卖反制结果可预期；坚持卖爆品不再越来越弱。

### 4.10 成长系统：结算页只留目标，其余进总部页

- **问题**：目标、金银铜、四维分、等级（LV.10 要 10700 分）、建设点/设施、成就六套系统全堆结算页；设施"可升级"话术与实际效果不符（待核实）。
- **改法**：①结算页只留目标 + 通道 + 钱 + 故事 + 下一轮按钮。②四维分、等级、建设点、成就、设施全部进总部页（成就馆 + 总部面板），结算页一行链接。③设施核查：Claude 指认每个设施的玩法效果；**有加成的写明数值，无加成的文案统一改为荣誉（"已点亮"），不再出现"升级/解锁玩法"表述**。④四维分计算公式：Claude 在执行时指认并写入方案附录，不得编数字；展示时写清"0–100 分由哪四维构成"。
- **验收**：结算页无四维分、无等级、无成就卡；总部页能看到全部六套系统的数值与含义。

## 5. 视觉方案（按截图与 styles.css 的实测问题改）

- **层级**：一屏只一个视觉焦点。主数字 ≥30px、标题 18px、正文 14px、注释 12px；**注释不得承载决策信息**（决策信息必须 ≥14px 且用 #e6eff3 以上亮度）。卡片分级：主卡深色 + 绿边，次卡无边框、不抢视线。
- **对比**：正文对比度 ≥4.5:1。现 11px 的 #8da9b2 / #85a4b0 在 #0b1d25 上不达标 → 注释字号提到 12px、颜色提到 #a4bdc7 以上；决策数字用 #e6eff3、17px+。
- **主行动唯一**：每屏一个 #adff2f 实心按钮，其余全部幽灵按钮；主按钮文案是动词。01/02/03 + 3 个 tab + 2 个返回并存的局面废止。
- **场景化**：每个环节专属背景色/插画头图，不再是统一 `.v2-panel`；地图进度（总部图 + 当前房间高亮 + 已完成打勾）取代文字步骤条。
- **动效**：房间切换 0.3 秒滑动/淡入；数字滚动；W5 货箱动画与 W1 选中动画保留；禁止连续镜头移动。
- **移动端**：触摸区 ≥44pt（沿用 3D-074）；结算页单列；模式选择页废止后，竖屏卡片 below fold 问题随之消失。

## 6. 交互方案

- **一步一行动**：主按钮文案是动词；完成即时反馈（勾 + 数字变化）；选完直接进下一环节，不用回出口再进门（P0.1 已实现，保留）。
