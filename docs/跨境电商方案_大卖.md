# 《大卖》—— 全球跨境电商 Roguelite 经营方案

> 整理日期：2026-10-19。**方案一（Roguelite 创业局）的局制结构 × 方案二（小店人生）的真实账本+叙事**，背景换成全球跨境电商。
> 工作标题：《大卖》——从华强北档口，到全球。

## 一句话

你是一名深圳跨境卖家，每一局 = 一个销售季（黑五季 / Prime Day / 圣诞季）：选站点、选品、发货、打广告、斗跟卖、扛差评——30 天内达成利润目标，失败复盘重开，成功解锁新站点、新类目。从铺货小卖，一路做到品牌大卖。

## 为什么是方案一 × 方案二

| 取自方案一（创业局） | 取自方案二（小店人生） |
|---|---|
| Roguelite 局制：一局 45 分钟，一个销售季 | 一本真账：利润 vs 现金流 |
| 局内 draft 构筑（选品/营销/供应链三系） | 常客→这里变成"人物"：工厂、货代、客服、买家 |
| 局后复盘：自动归因本局死因 | 街区叙事→这里变成"卖家生态"叙事 |
| Meta 成长：解锁新站点/新类目 | 情感钩子：每一单背后的故事 |

跨境电商是这两个方案的**最佳载体**：它天然有"局"（大促季）、天然有"真账"（物流/关税/广告三座大山）、天然有故事（华强北、跟卖、封店）。

## 世界观

2019–2026 的深圳：华强北的档口、坂田的写字楼、观澜的仓库。平台叫 **GlobalMart**（虚构，影射但不点名，规避法律风险），站点：北美、欧洲、东南亚、中东、拉美。你开局是一个 10 平米档口 + 一台电脑 + 3 万启动资金。

## 核心循环（局内 30 天）

- **Day 0 选局**：选销售季（黑五/Prime Day/圣诞）→ 选站点（种子：北美成熟红海 / 东南亚增长蓝海 / 中东高客单价）→ 选类目方向
- **每日**：
  1. 选品/补货决策（看数据：搜索量、竞争度、利润率）
  2. 广告投放（关键词竞价，定预算）
  3. 订单履约（FBA 发货 / 自发货抉择）
  4. 客服（差评、退货、A-to-Z 索赔）
  5. 夜晚算账：**今天到底赚没赚**（利润 vs 现金：货还在海上飘，钱还没回来）
- **每周**：广告复盘（ACOS 是否超标）、库存预警（断货=排名掉）、跟卖/差评事件
- **Day 30 结算**：达利润目标→晋级（解锁新站点/新类目）；失败→复盘报告（死因：选品？断货？广告烧穿？被跟卖？）

## 关键系统

### 1. 选品系统（真实模拟核心）
- 数据看板：搜索量、竞争度、评论数中位数、价格带——四个维度决定"红海还是蓝海"
- 1688/工厂谈价：MOQ（最小起订量）vs 资金占用的经典抉择；账期谈判（老陈给你 30 天账期，但要搭他滞销的货）
- 差异化改造：开模/改包装/做认证（CE/FCC），投入 vs 溢价

### 2. 供应链系统（跨境第一杀手）
- 头程三选一：**海运**（便宜 1/5 价格，但 30–40 天，资金全压在海上）/ **空运**（快但贵，吃掉利润）/ **海空联运**（折中）
- 旺季事件：黑五前海运涨价 3 倍、甩柜（你的货被卸下来了，断货警告）
- 海外仓：FBA 仓储费（Q4 翻倍）、长期仓储费，压货=交租
- 关税/合规事件：反倾销税、EPR、VAT——真实跨境人的噩梦，做成随机事件卡

### 3. 营销系统（局内构筑三系之一）
- 关键词竞价：出价、预算、ACOS（广告销售成本比），烧钱换排名
- 评价系统：早期"要好评"抉择——**刷单**（高风险高回报，可能封店）vs 自然积累（慢）
- 大促提报：秒杀/BD 提报，流量爆发但利润薄

### 4. 攻防系统（跟卖与风控）
- 被跟卖：价格战 / 赶跟卖（Test Buy + 投诉）/ 品牌备案（R标）防御
- 账号风控：绩效指标（ODR 超标警告→封店），每一次"走捷径"都在攒风险值
- 差评危机：1 星差评出现，转化率掉 30%——删差评（灰色）/ 回复 / 送礼挽回

### 5. 财务系统（方案二的"真账本"）
- 利润 vs 现金流双视图：**账面盈利但现金断裂**是本游戏最常见的死法（和真实一样）
- 回款周期：平台 14 天回款，应收账款可视化
- 汇率：美元/欧元结算，汇率波动吃掉 3–5 个点利润是常态

### 6. 人物故事线（方案二的"叙事"）
- **老陈**（工厂老板）：给你账期，但他自己也被上游逼债；你拖账期，他可能倒闭——你的供应链断了
- **阿强**（货代）：旺季帮你抢舱位，但"加钱插队"游走在灰色地带
- **小林**（客服）：每天面对奇葩买家，她的情绪值影响差评回复质量
- **隔壁老王**（跟卖者）：从跟卖你的爆款，到被你反杀，到最后你们合作——一条完整的"对手"弧光
- **买家故事**：每个差评/好评背后是一个真实买家（"这个加湿器是我妈化疗时病房里用的"）——好评返现之外的情感重量

## 目标分层

- **短期**：今天不断货、不被跟卖、ACOS 别爆
- **中期**：本销售季达利润目标；拿下类目 Best Seller 小旗子
- **长期**：五大站点全通关；从铺货小卖→品牌大卖→收购工厂（终极：做自己的品牌，出海上市）；"跨境人物图鉴"全收集

## 5 要素速评

- **特别想玩** ★★★★★：牛熊大促的天然节奏 + 跟卖攻防 + 开盲盒式选品，三重多巴胺
- **盈利** ★★★★★：买断 + DLC（新站点包：中东/拉美/非洲；新类目包：3C/家居/服装）；题材在跨境圈自带传播（深圳卖家社群、知无不言、跨境社群都是天然渠道）
- **真实模拟** ★★★★★：选品/物流/广告/关税/汇率——全是真参数，跨境人玩了会说"太真了"
- **故事性** ★★★★★：工厂、货代、跟卖、买家——每个都是现成的剧本
- **不过时** ★★★★★：贸易永恒；大促季、选品、物流是百年外贸的母题，换个平台名依然成立

## 单人可行性：★★★★☆

纯 2D UI 驱动（数据看板 + 日历 + 账本 + 人物对话），无复杂美术；核心是数值系统（选品模型、广告模型、物流模型），可数据驱动、快速迭代。内容（事件卡、人物剧本）可分 DLC 批次生产。

## 风险与对策

1. **真实 vs 好玩的平衡**：真跨境全是 Excel 和等船期。对策：保留"三座大山"（物流、广告、跟卖），其余抽象成事件卡；时间压缩（1 天=2 分钟）。
2. **平台影射的法律风险**：用虚构平台名 GlobalMart，机制影射但不点名；刷单/删差评等灰色玩法做成"风险抉择"而非教程。
3. **数值调参**：广告 ACOS、物流时效、跟卖强度三组参数决定手感，需要找真实卖家做顾问验证（深圳不缺这样的人）。
4. **题材受众**：核心受众是跨境从业者+经营游戏玩家，泛化靠"搞钱爽感"（参考《大多数》这类"打工模拟"的破圈路径）。

## 最小可玩原型（MVP 验证清单）

先做"一季黑五 × 北美站 × 3C 类目"的最小闭环，验证三个问题：
1. 选品→发货→广告→算账的循环**转得起来**吗？（核心循环验证）
2. 断货/跟卖/差评事件**有紧张感**吗？（戏剧张力验证）
3. 夜晚算账时玩家**关心现金流**吗？（"真账本"是最差异化的点，必须成立）

预计：2D 原型 + 50 张事件卡 + 5 个人物，验证"好不好玩"不需要美术。
