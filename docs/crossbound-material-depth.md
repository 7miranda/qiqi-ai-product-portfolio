# 工业空间与材质层次

2026-10-29，基于 main `37a54d8`。用户反馈之前仍偏平，要求按照游戏 UI 参考增加空间、渐变和材质，同时保留银白 3D 园区与整体量感。

## 本轮实现

- 复用现有工业厂区环境图，用统一方向的蓝色环境光衔接首页与经营空间。
- 首页服务、开场、情报、案例及 AI 区加强金属受光边缘、深蓝玻璃、局部反射与接触阴影。服务三卡分别接受同一光源的不同位置照明，后方厂区与前方卡片有明暗分离。
- 弹层、工作台、商品展示舱和数据区使用共享材质变量；产品舞台保留顶光和接地阴影，工作台与数据槽有独立前后层次。
- 现有平面按钮、返回位置、键盘焦点、选中状态和经营顺序保持；静态服务成果说明不做成输入框。
- 园区与产品几何、镜头、Canvas 尺寸、图片比例、W3 栅格和移动端滚动保持。课程与所有经营逻辑保持原样。

新增两份只负责表面的 CSS，由现有生成器加载并统一内容版本。未引入新库、额外动画或新图片，环境图的来源与提示词见 [资产记录](./crossbound-spatial-hud.md)。

## 首页原色与无底板文字

用户进一步指出首页与地球仍过浅、标题后多出矩形。原因是 #18 中的 `eG` 提亮补丁将首页地球从 `#030a0d` 改为 `#1c3b50`；此前仅回调 CSS，未撤销此补丁。另外标题的 `::before` 装饰形成了矩形底板。

本次删除地球提亮补丁及测试中的对应豁免，让原生地球函数重新纳入完整字节保留校验。首屏背景、桌面与手机遮罩均恢复 `a2691cb` 的原值；删除标题底板和后加的地球光晕。其他服务区、园区、布局、比例与交互保持。

实图检查：首屏背景 `rgb(3,8,11)`，标题透明、边框0、标题与地球伪元素均为 `none`；1440px桌面及390px手机可读、无横向溢出，英国/新加坡切换正常。95项Crossbound测试、正式构建与4项导出测试通过。[首页证据](./screenshots/crossbound-dark-homepage/)。
